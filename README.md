# Позови — первая версия

Сервис сайтов-приглашений на свадьбу и праздники. Рабочее название «Позови» временное. ТЗ лежит в папке проекта `idei/tz-mvp.md`.

## Что уже работает

- **Лендинг** `/` с примерами, ценами и вопросами.
- **Конструктор** `/new`: фото для обложки (JPG, PNG, WebP до 8 МБ, хранятся в `data/uploads`), тип события, имена, дата, место, программа, дресс-код и цвета, контакт, срок ответа, один из 14 шаблонов (Усадьба, Белые ночи, Афиша, Конверт, Звёздное небо, Море, Цветение, Акварель, Неон, Диско, Ретро, Плёнка, Минимал, Детский). У каждого своя анимация на обложке, гостю можно с ней поиграть, а на «Приду» летит конфетти. Все шаблоны: `/templates`.
- **Сайт-приглашение** `/i/<адрес>`: обложка с обратным отсчётом, программа, место со ссылкой на Яндекс Карты, дресс-код, анкета гостя с согласием на обработку данных, подвал «Сделано в Позови» с меткой источника. Если есть фото, обложка строится на нём во весь экран, и оно же уходит в превью ссылки в мессенджерах (Open Graph).
- **Кабинет** `/c/<секретный ключ>`: сводка, таблица ответов, выгрузка CSV для Excel, ссылка для гостей, редактирование.
- **Демо:** `/i/demo-<шаблон>` для каждого шаблона, кабинет `/c/demo-kabinet`. У первых трёх демо настоящие фото, у остальных обложку рисует анимация.
- **Фото демо и главной** лежат в `public/photos`, взяты с Unsplash (лицензия Unsplash разрешает коммерческое использование без указания автора). Перед запуском лучше заменить на фото реальных клиентов с их согласия.
- Черновик политики конфиденциальности `/privacy` (проверить у юриста).

Скриншоты в папке [screenshots](screenshots/).

## Как запустить

Нужен Node.js 18 или новее, внешних библиотек нет.

```
npm start
```

Откройте http://localhost:3000. Настройки через переменные окружения: `PORT`, `BASE_URL` (публичный адрес сайта, нужен для ссылок и превью), `DATA_DIR` (где хранить `db.json`).

## Публикация

- **Витрина на GitHub Pages** (главная, три демо-приглашения, демо-кабинет): адрес https://poluci.github.io/polusi/. Собирается командой `npm run build:pages` в папку `dist`, её содержимое лежит в ветке `gh-pages`, Pages раздаёт эту ветку. Формы там не работают, им нужен сервер.
- **Полная версия с сервером на Render** (бесплатно): render.com → New → Blueprint → этот репозиторий, настройки в `render.yaml`. На бесплатном тарифе сервер засыпает без посетителей, а `data/` стирается при перезапуске, так что это для показа, не для настоящих гостей.
